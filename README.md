# 林一舟 · AIGC Portfolio

这是一个可部署到 Vercel、Netlify、Cloudflare Pages 或 GitHub Pages 的静态作品集网站。页面按面试浏览逻辑排列为：可口可乐、长安卫、全息复刻工作流、The Sandbox。每个项目都参考原作品集中的小标题和内容结构，并将横版、竖屏视频拆成独立区域，按原始比例展示。页面内嵌原作品集中的 47 支原始 MP4 视频，支持封面预览、直接播放、暂停、拖动进度和全屏观看；同一时间只会播放一个视频。
页面文案已精简为两类：个人信息和项目介绍。首页口号、泛化说明、统计数字和联系区宣传文案已移除；视频标题与项目介绍保留，47 支视频的原始比例、封面、全屏和单视频播放逻辑不变。

直接将本目录上传到静态托管平台即可，无需构建命令。发布目录为项目根目录。由于视频文件体积较大，建议使用 Vercel、Netlify 或 Cloudflare Pages 的 Git 部署方式，并注意平台的单文件与总容量限制。

## 投递前替换

请在 `index.html` 中替换邮箱、手机号、微信、城市和其他个人信息。原始视频文件位于 `assets/` 中，文件名以 `media-*.mp4` 结尾；`*-cover.jpg` 只是从原视频首帧生成的封面，不是压缩后的视频。视频文件和封面文件要与 `index.html` 一起部署，不要单独移动或重命名。
